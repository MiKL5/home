## **🧭 Navigation**
Le dock est en bas de tous les écrans. Il y a 7 rubriques :
* 🏠 Accueil ;
* 👤 Présentation ;
* 🎓 Formation ;
* 💼 Les projets ;
* 📬 Contact ;
* 3 options sont accessibles par le menu option <b><kbd>⋮</kbd></b> :
    * 🌗 Un switch pour basculer du clair au sombre.
    * 🛡️ La politique de confidentialité
    * ⚖️ L'accès aux mentions légales
## **🛠️ Technologies utilisées**
* **HTML5** pour la structure sémantique.
* **CSS** (minifié) pour une performance d'affichage.
* **Tailwind CSS** (mode CLI) pour un design atomique, sans runtime JavaScript (Sobriété numérique).
* **JavaScript** pour l'interactivité (filtres, recherche, dark mode, navigation) sans dépendances lourdes.
* **Git** pour la gestion de version et le déploiement.
* **Web Storm** éditeur.
* **Images optimisées** (WebP, SVG).
* **SEO** : balises meta, Open Graph, canonical, données structurées JSON-LD.

### **♿ Accessibilité (A11y)**
* **Standard WCAG** ➔ Respect des contrastes, navigation au clavier, et gestion du focus.
* **Attributs ARIA** ➔ Utilisation des rôles `dialog`, `switch`, `list` et des tags `aria-current` pour une expérience inclusive.
## **🔒 Sécurité & confidentialité**
* **Privacy by Design** ➔ ni donnée personnelle collectée, ni de cookies de tracking ni d’analyse tiers.
* **Conformité RGPD** ➔ Politique de confidentialité explicite et transparente.
## **🌱 Sobriété numérique**
* Design minimaliste et ressources optimisées pour réduire l’empreinte carbone.
* Badge EcoIndex A.
