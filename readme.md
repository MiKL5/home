# **Portfolio**

Il y a quatre rubriques :

- Accueil (Une brève introduction sur moi-même et mes aspirations professionnelles.) ;
- Présentation (parcours, compétences, <!--projets-->) ;
- Formations (diplômes et certifications) ;
- Contact.

* Un switch en haut à droite permet de basculer entre les modes sombre et clair.
* Le dock est à gauche ou en bas sur les petits écrans.

## Technologies utilisées

- **CSS** pour le style.
- **JavaScript** pour l'interactivité et fonctionnalités dynamiques.
- **Tailwind CSS** est un framework CSS pour un design moderne et responsive.
- **Git** pour la gestion de version et déploiement du code.
